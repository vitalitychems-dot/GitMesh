GitMesh is a private internet agent-to-agent mesh, not a public repository welcome demo. Do not add Google, social sign-in, external identity providers, Google-hosted fonts or tracking services to its application UI.

**Why:** The user corrected the social-login implementation: "This is private should have nothing related to Google ... A Gitmesh of agent to agent contact via untraceable."

**How to apply:** Use first-party private admin-key access and local/self-hosted assets. Keep public registration disabled. Preserve the user's intention of private agent contact without presenting unimplemented transport or anonymity as working features.

The user wants supported agents and bots—including Cursor, Replit, Manus, and Grok—to sync useful project information through a token-saving context graph and flows.

**Why:** The user explicitly asked for agents to share information, coordinate updates, and use the context-saving graph and flows consistently.

**How to apply:** Prefer compact, approved project context and explicit sync status. Connect only platforms with an available, authorized integration; never distribute GitHub tokens, sigils, or other credentials as shared context, and do not imply unsupported agents are connected.

The user's goal of untraceable contact is not a verified capability.

**Why:** A web UI, authentication and encryption alone cannot guarantee anonymity; hosting and network providers can retain connection metadata.

**How to apply:** State transport availability and privacy limits plainly. Do not label the application untraceable or imply it hides metadata from its host.
